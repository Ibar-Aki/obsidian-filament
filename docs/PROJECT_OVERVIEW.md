# 🌟 ポートフォリオサイト プロジェクト概要

## これは何？

**ビジネス向けのポートフォリオ＆ブログサイト**です。

自分のサービスを紹介したり、ブログ記事を書いたり、お問い合わせを受け付けたりできます。

---

## 何ができるの？

| 機能 | 説明 |
|------|------|
| 🏠 トップページ | あなたのビジネスを魅力的にアピール |
| 💼 サービス紹介 | 提供するサービスを一覧・詳細で表示 |
| 📝 ブログ | 記事を書いて情報発信 |
| 📬 お問い合わせ | フォームからお問い合わせを受付 |

---

## どうやって動いてるの？

```
┌─────────────────────────────────────────────────────┐
│                    あなたのサイト                      │
│                  (Next.js製の見た目)                   │
└───────────────┬─────────────────────┬───────────────┘
                │                     │
                ▼                     ▼
        ┌───────────────┐     ┌───────────────┐
        │   microCMS    │     │   SSGform     │
        │ (記事データ)   │     │ (問い合わせ)   │
        └───────────────┘     └───────────────┘
```

### 使っている技術

| 技術 | 役割 | 費用 |
|------|------|------|
| **Next.js** | サイトの見た目を作る | 無料 |
| **Tailwind CSS** | デザインをキレイにする | 無料 |
| **microCMS** | ブログ・サービス情報を管理 | 無料プランあり |
| **SSGform** | お問い合わせフォーム | 無料プランあり |
| **Vercel** | サイトを公開する | 無料プランあり |

> 💡 すべて無料プランで始められます！

---

## 始め方（3ステップ）

### Step 1: 外部サービスに登録

1. **microCMS** (<https://microcms.io>) でアカウント作成
2. **SSGform** (<https://ssgform.com>) でフォーム作成
3. **Vercel** (<https://vercel.com>) でアカウント作成

### Step 2: 設定ファイルを作成

プロジェクトフォルダに `.env.local` ファイルを作って、↓をコピペ：

```
MICROCMS_SERVICE_DOMAIN=（microCMSで取得）
MICROCMS_API_KEY=（microCMSで取得）
NEXT_PUBLIC_SSGFORM_ENDPOINT=（SSGformで取得）
```

### Step 3: サイトを起動

```bash
npm run dev
```

ブラウザで <http://localhost:3000> を開くと完成！🎉

## よくある質問

**Q: プログラミングの知識は必要？**
> 記事の投稿だけならmicroCMSの画面から簡単にできます。
> デザインを変えたい場合はコードの編集が必要です。

**Q: 費用はかかる？**
> すべて無料プランで始められます。
> アクセス数が増えたら有料プランの検討を。

**Q: スマホ対応してる？**
> はい！レスポンシブデザインでスマホでもキレイに表示されます。
