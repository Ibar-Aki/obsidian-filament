## 1. そもそもの話：何をするの？

### あなたのサイトには「データ」が必要

サイトには以下のデータが必要です：

| データ | 例 |
|--------|-----|
| ブログ記事 | 記事タイトル、本文、画像 |
| サービス情報 | サービス名、説明、価格 |
| お問い合わせ | お客様からのメッセージ |

### 問題：このデータをどこに保存する？

プログラマーでない人が記事を書くたびにコードを編集するのは大変！

### 解決策：外部サービスを使う

| サービス | 役割 |
|----------|------|
| **microCMS** | ブログ・サービス情報を管理する場所（Word感覚で記事が書ける） |
| **SSGform** | お問い合わせを受け取る場所（メールで通知が届く） |

## 2. microCMSって何？なぜ必要？

### microCMSとは

「**ヘッドレスCMS（コンテンツ管理システム）**」と呼ばれるサービスです。

難しく聞こえますが、要するに：
> **「Wordみたいに記事を書くだけで、サイトに自動で反映される魔法の道具」**

### なぜmicroCMSを選んだ？

| 理由 | 説明 |
|------|------|
| 🇯🇵 日本製 | 管理画面が全部日本語で分かりやすい |
| 💰 無料で十分 | 個人サイトなら無料プランで余裕 |
| 📱 スマホ対応 | スマホからも記事が書ける |
| 🎯 シンプル | 余計な機能がなくて迷わない |

### 無料プランの制限（参考）

- 3つまでのAPI（今回は「blogs」「services」の2つなのでOK）
- 月10,000リクエストまで（個人サイトなら十分）
- チームメンバー3人まで

## 3. microCMSの設定手順

### Step 3-1: アカウント作成

1. <https://microcms.io> にアクセス
2. 「無料ではじめる」をクリック
3. メールアドレスとパスワードを入力して登録
4. メールが届くので、確認リンクをクリック

### Step 3-2: サービス（プロジェクト）を作成

1. ログイン後、「サービスを作成」をクリック
2. サービス名を入力（例：`my-portfolio`）
3. サービスの説明を入力（任意）
4. 「作成」をクリック

> 💡 **サービスID**（URLの一部になる英数字）をメモしておいてください。
> 後で `.env.local` に書きます。

### Step 3-3: ブログ用のAPIを作成

1. 左メニューの「コンテンツ（API）」→「+ 追加」をクリック
2. **API名**: `ブログ`
3. **エンドポイント**: `blogs`（半角英字で）
4. **APIの型**: `リスト形式` を選択
5. 「作成」をクリック

### Step 3-4: ブログのフィールド（項目）を設定

「APIスキーマ」タブで、以下の3つのフィールドを追加：

#### フィールド1: タイトル

| 項目 | 入力値 |
|------|--------|
| フィールドID | `title` |
| 表示名 | `タイトル` |
| 種類 | `テキストフィールド` |
| 必須 | ✅ チェック |

#### フィールド2: 本文

| 項目 | 入力値 |
|------|--------|
| フィールドID | `content` |
| 表示名 | `本文` |
| 種類 | `リッチエディタ` |
| 必須 | ✅ チェック |

#### フィールド3: アイキャッチ画像

| 項目 | 入力値 |
|------|--------|
| フィールドID | `eyecatch` |
| 表示名 | `アイキャッチ画像` |
| 種類 | `画像` |
| 必須 | ❌ チェックしない |

1. 右上の「保存」をクリック

### Step 3-5: サービス用のAPIを作成

1. 「コンテンツ（API）」→「+ 追加」をクリック
2. **API名**: `サービス`
3. **エンドポイント**: `services`
4. **APIの型**: `リスト形式`
5. 「作成」をクリック

### Step 3-6: サービスのフィールドを設定

以下の6つのフィールドを追加：

#### フィールド1: スラッグ（URL用）

| 項目 | 入力値 |
|------|--------|
| フィールドID | `slug` |
| 表示名 | `スラッグ（URL用）` |
| 種類 | `テキストフィールド` |
| 必須 | ✅ チェック |

> 💡 スラッグとは：URLに使う英数字の名前です。
> 例：`web-design` → サイトでは `/services/web-design` になります。

#### フィールド2: タイトル

| 項目 | 入力値 |
|------|--------|
| フィールドID | `title` |
| 表示名 | `タイトル` |
| 種類 | `テキストフィールド` |
| 必須 | ✅ チェック |

#### フィールド3: 説明

| 項目 | 入力値 |
|------|--------|
| フィールドID | `description` |
| 表示名 | `説明` |
| 種類 | `テキストエリア` |
| 必須 | ✅ チェック |

#### フィールド4: 価格

| 項目 | 入力値 |
|------|--------|
| フィールドID | `price` |
| 表示名 | `価格` |
| 種類 | `テキストフィールド` |
| 必須 | ✅ チェック |

#### フィールド5: 画像

| 項目 | 入力値 |
|------|--------|
| フィールドID | `image` |
| 表示名 | `画像` |
| 種類 | `画像` |
| 必須 | ❌ チェックしない |

#### フィールド6: デモURL

| 項目 | 入力値 |
|------|--------|
| フィールドID | `demo_url` |
| 表示名 | `デモURL（YouTube等）` |
| 種類 | `テキストフィールド` |
| 必須 | ❌ チェックしない |

「保存」をクリック

### Step 3-7: APIキーを取得

1. 右上の ⚙️（サービス設定）をクリック
2. 左メニューの「権限管理」→「APIキー」をクリック
3. **APIキー**（長い英数字の文字列）をコピーしてメモ

> ⚠️ **このAPIキーは絶対に他人に見せないでください！**

### Step 3-8: テスト用の記事を作成

1. 左メニューの「ブログ」をクリック
2. 「+ 追加」をクリック
3. タイトルと本文を適当に入力
4. 「公開」をクリック

これでmicroCMSの設定は完了です！🎉

## 4. SSGformって何？なぜ必要？

### SSGformとは

「**静的サイト用のお問い合わせフォームサービス**」です。

要するに：
> **「フォームに入力された内容を、あなたのメールに届けてくれるサービス」**

### なぜSSGformを選んだ？

| 理由 | 説明 |
|------|------|
| 🇯🇵 日本製 | 日本語で分かりやすい |
| 💰 完全無料 | 無料プランで月100件まで |
| 📧 メール通知 | お問い合わせがあるとメールで通知 |
| 🔒 スパム対策 | 迷惑メール対策機能付き |

## 5. SSGformの設定手順

### Step 5-1: アカウント作成

1. <https://ssgform.com> にアクセス
2. 「無料で始める」をクリック
3. メールアドレスとパスワードを入力
4. メール確認リンクをクリック

### Step 5-2: フォームを作成

1. ログイン後、「新しいフォームを作成」をクリック
2. フォーム名を入力（例：`お問い合わせフォーム`）
3. 通知先メールアドレスを入力（お問い合わせを受け取りたいアドレス）
4. 「作成」をクリック

### Step 5-3: エンドポイントURLを取得

フォーム作成後、以下のようなURLが表示されます：

```
https://ssgform.com/s/xxxxxxxxxxxxxxxxxx
```

このURLをコピーしてメモしておいてください。

これでSSGformの設定は完了です！🎉

## 6. 設定ファイルの作成

### Step 6-1: 設定ファイルを作成

プロジェクトフォルダ（`obsidian-filament`）の直下に `.env.local` というファイルを作成します。

> ⚠️ ファイル名は `.env.local` です（先頭にドットがあります）

### Step 6-2: 内容を入力

以下をコピーして、あなたの情報に書き換えてください：

```
# microCMS設定
MICROCMS_SERVICE_DOMAIN=ここにサービスID
MICROCMS_API_KEY=ここにAPIキー

# SSGform設定
NEXT_PUBLIC_SSGFORM_ENDPOINT=https://ssgform.com/s/ここにあなたのID
```

#### 例

```
MICROCMS_SERVICE_DOMAIN=my-portfolio
MICROCMS_API_KEY=abcdefghijklmnopqrstuvwxyz123456
NEXT_PUBLIC_SSGFORM_ENDPOINT=https://ssgform.com/s/abc123xyz
```

ファイルを保存してください。
